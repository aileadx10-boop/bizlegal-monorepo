# I Ran a Revenue-Leak Report on My Own Practice

_Every number in this article is a placeholder in [brackets] until I fill it from my own export. Nothing here is invented; if a bracket is still visible, the number was not available._

Most of the advice about law-firm revenue is aimed at firms with a finance team. I run a practice by myself. The billing software holds the answer to a question I had never asked it plainly: how much of last quarter's work was invoiced late, and how much was never invoiced at all?

So I exported the invoices and the time entries as CSV and read them back with a tool I built for exactly that. Here is what it printed, and what I did about it.

## The setup, and what it did not touch

Two files, exported the same way any billing tool exports them. Before either file left my browser, every client, matter and invoice identifier was replaced with a code — "Client 01", "Matter 01-02", "INV-0001" — and the key stayed on my machine. The server only ever saw codes and amounts. Nothing connected to my inbox or my practice software.

Accessibility

Accessibility Statement

Last reviewed: 2025

BizLegal AI (operated by BizLegal AI) is committed to ensuring digital accessibility for people with disabilities. We continually improve the user experience for everyone and apply relevant accessibility standards.

Our Commitment

  • Semantic HTML structure for screen readers
  • Sufficient color contrast ratios (WCAG 2.1 AA target)
  • Keyboard navigation support for all interactive elements
  • Descriptive link text and form labels
  • Responsive design for mobile and assistive device use

Known Limitations

The Three.js 3D background animation is decorative and not conveyed to assistive technologies. Some complex interactive elements (clause editor) may have limited screen reader support. We are working to improve these.

# BizLegal AI — Robots & AI Crawler Policy
# Effective 2026-06-18. Owner: Moses Dor, BizLegal AI FZE.
#
# This file is served from Vercel/CDN. If you are seeing a Cloudflare
# "managed content" template override this file, disable that toggle at:
#   Cloudflare dashboard → domain → Security → Bots → AI Crawl Control → OFF
#   Cloudflare dashboard → domain → Security → Settings → Managed robots.txt → OFF
# Once OFF, this file is the authoritative robots.txt.
#
# We ALLOW all well-behaved crawlers including AI search and AI
# retrieval-augmented generation (RAG) systems. We DENY only training
# scrapers that ignore robots.txt and abusive bulk-fetchers.

# GEO / AEO strategy: we WANT Claude, ChatGPT, Gemini, Perplexity, Grok,
# Llama, and Google SGE to find, index, and quote our content. They
# drive top-of-funnel discovery for compliance buyers. We are NOT
# concerned about model-training-set dilution — our content is B2B
# compliance intelligence, not training data fodder.

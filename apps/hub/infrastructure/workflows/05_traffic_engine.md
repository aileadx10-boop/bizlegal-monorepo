# Workflow 05 — Traffic Engine

**Trigger**: After each published post (from 03_content_writer) + weekly cron  
**Owner**: n8n → combination of HTTP requests and Python scripts  
**Agent**: Ollama `gemma2:9b` for meta generation; n8n for distribution  
**Output**: SEO meta updated in Supabase, sitemap regenerated, social scheduled

---

## Purpose

Drive organic traffic to bizlegal-ai.com via three channels: SEO (Google Search), social media (LinkedIn/Twitter/Substack), and newsletter. Every published piece of content automatically runs through this engine.

---

## Channel 1: SEO

### On-Page SEO (auto-generated at publish time)
```
For each new post:
1. gemma2:9b generates → title_tag (≤60 chars), meta_description (≤155 chars), OG image prompt
2. Supabase update → posts.seo_title, posts.seo_description
3. Next.js export const metadata → reads from Supabase at build time
4. OG image → /api/og?title={encoded_title} (already live)

Target keywords per category:
  SEC     → "SEC crypto enforcement 2026", "DeFi regulation SEC"
  MiCA    → "MiCA compliance", "MiCA stablecoin rules"
  VARA    → "VARA crypto license Dubai", "VASP compliance UAE"
  FATF    → "FATF travel rule crypto", "AML crypto compliance"
  GDPR    → "GDPR crypto compliance", "blockchain GDPR"
```

### Sitemap
```
After publish → POST to /api/revalidate?secret={REVALIDATION_SECRET}
Sitemap at: bizlegal-ai.com/sitemap.xml (auto-generated by Next.js)
Submit to: Google Search Console (manual, monthly)
```

### Backlink Strategy (manual, tracked in Notion)
```
Targets:
  - Fintech legal blogs (guest posts)
  - Crypto media (CoinDesk, The Block press releases)
  - Law firm directories
  - Regulatory body acknowledgement pages
```

## Channel 2: Social Media

### Flow
```
Published post → publisher_buffer.py
  → LinkedIn (company page: linkedin.com/company/112614911)
  → Twitter/X (@bizlegal_ai)
  → Instagram (@dorinnovations) — visual card only
  → Pinterest (board: regulatory-intelligence)
  → Substack (cross-post full article)
  → Facebook page
```

### Post Template (auto-generated by gemma2:9b)
```
LINKEDIN:
  Hook (1 line) + 3-5 bullet key points + risk score visual
  CTA: "Full analysis → link"
  Hashtags: #FinTech #Compliance #[Category] #BizLegalAI

TWITTER/X:
  Hook (240 chars) + risk badge emoji + link
  Thread optional for high-risk (> 70) items

INSTAGRAM:
  Visual card (OG image) + 3-line caption + link in bio
```

### Scheduling
```
LinkedIn: Mon/Wed/Fri 09:00 CET
Twitter:  Tue/Thu/Sat 10:00 CET + real-time for urgent (risk > 80)
Instagram: 2x/week
Substack: Weekly digest (Friday 08:00 UTC)
```

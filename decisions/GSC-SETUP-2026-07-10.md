"""
gsc_setup.md — 2026-07-10 GSC property setup for bizlegal-ai.com fleet.

Moses: 10 minutes to set up Google Search Console for all 8 subdomains.
Required for indexing feedback, structured data validation, and the
Search Console API (so agents can auto-submit sitemaps).

=============================================================
STEP 1: Add all 8 properties to GSC
=============================================================
URL: https://search.google.com/search-console

For EACH of these 8 URLs, click "Add Property" → URL prefix:
  1. https://bizlegal-ai.com/
  2. https://tracr.bizlegal-ai.com/
  3. https://brai.bizlegal-ai.com/
  4. https://lexaudit.bizlegal-ai.com/
  5. https://docai.bizlegal-ai.com/
  6. https://forge.bizlegal-ai.com/
  7. https://leadforge.bizlegal-ai.com/
  8. https://blog.bizlegal-ai.com/  (if blog is on a separate project)

=============================================================
STEP 2: Verify each property (DNS TXT record)
=============================================================
For EACH property, GSC will give you a TXT record like:
  google-site-verification=abc123def456...

Add this TXT record to your DNS provider (where bizlegal-ai.com is hosted).
For Cloudflare DNS: Add record → Type=TXT, Name=@, Content=google-site-verification=...

Repeat for each subdomain (Name=tracr, Name=brai, etc.).

If DNS is not in Cloudflare, use your provider's UI.

=============================================================
STEP 3: Submit sitemaps (5 min for all 8)
=============================================================
For EACH property, GSC → Sitemaps → paste URL:
  1. https://bizlegal-ai.com/sitemap.xml
  2. https://tracr.bizlegal-ai.com/sitemap.xml
  3. https://brai.bizlegal-ai.com/sitemap.xml
  4. https://lexaudit.bizlegal-ai.com/sitemap.xml
  5. https://docai.bizlegal-ai.com/sitemap.xml
  6. https://forge.bizlegal-ai.com/sitemap.xml
  7. https://leadforge.bizlegal-ai.com/sitemap.xml
  8. https://blog.bizlegal-ai.com/sitemap.xml

=============================================================
STEP 4: Optional — service account for API access (10 min)
=============================================================
If you want agents to auto-poll GSC and submit sitemaps:

  1. Go to https://console.cloud.google.com/
  2. Create or select a project (e.g. "bizlegal-gsc")
  3. Enable "Google Search Console API"
  4. Create a Service Account:
     IAM & Admin → Service Accounts → Create Service Account
     Name: bizlegal-gsc-agent
     Role: Owner (or Search Console User)
  5. Download the JSON key, save as `gsc_service_account.json`
  6. In GSC, for EACH of the 8 properties:
     Settings → Users and permissions → Add user
     Email: bizlegal-gsc-agent@<your-project>.iam.gserviceaccount.com
     Permission: Owner
  7. Set the JSON in Hetzner .env:
     GSC_SERVICE_ACCOUNT_JSON=/opt/bizlegal/curator/gsc_service_account.json

After this, the `gsc_indexnow_pinger.py` cron can also call
`searchconsole.sitemaps().submit()` programmatically.

=============================================================
DONE — Expected outcome after 24 hours
=============================================================
- GSC "Pages" report shows indexed count for each subdomain
- Structured data report shows Product/FAQPage/Organization validation
- Core Web Vitals report starts collecting data
- Manual sitemap submissions get "Success" status

The structured data issue you already fixed (Product availability/brand/etc.)
will show as "Valid" in GSC within 1-3 days of next crawl.

=============================================================
WHY THIS MATTERS FOR $5K MRR
=============================================================
Without GSC: you can't see which pages are indexed, which have errors,
which keywords you're ranking for. SEO is flying blind.

With GSC: aeo_loop_v2 + content_enricher_v2 can see their own results
(impressions, clicks, average position) and optimize the right pages.
The seo_dispatcher can prioritize keywords with high impressions + low CTR.
This is the difference between "writing articles" and "writing articles
that rank and convert."

Combined with IndexNow (A10, ~1 min), every new article gets noticed by
Google + Bing + AI search engines within 24 hours instead of weeks.

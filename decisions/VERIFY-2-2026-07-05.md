BUG FOUND IN THE SIBLING FIX (fixed in this session, commit 1005086)
================================================================
  The line in weekly_health.py that the sibling session
  "restored" from the SyntaxError is NOT valid Python:
    by_agent.setdefault(a, {"ok": 0, "fail": 0, "other": 0})[KEY] += 1
  Where KEY is a complex conditional that returns a string.
  Python does not allow subscript-assignment to a
  setdefault-returned value in that chained form.

  BEFORE (the broken form):
    by_agent.setdefault(a, {"ok": 0, "fail": 0, "other": 0})[s if ... else ...] += 1

  AFTER (commit 1005086):
    if s in ("ok", "success"): bucket = "ok"
    elif s == "failed": bucket = "fail"
    else: bucket = "other"
    bucket_row = by_agent.setdefault(a, {"ok": 0, "fail": 0, "other": 0})
    bucket_row[bucket] = bucket_row.get(bucket, 0) + 1

    leads_7d=112 | high_score_7d=81 | agent_runs_7d=316

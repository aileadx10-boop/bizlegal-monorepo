### SUBJECT AREA 4: 🎯 AI PATTERNS & ARCHITECTURE (Advanced Workflows)

| Workflow | Pattern Type | Compliance & Risk Application |
|----------|-------------|-------------------------------|
| **Prompt Chaining** | Sequential AI refinement | **Multi-Stage Risk Assessment** — Draft → Review → Approval workflow for compliance reports |
| **Parallelization** | Multiple AI agents simultaneously | **Comprehensive Risk Scoring** — Parallel analysis: legal risk, financial risk, operational risk, reputational risk |
| **Routing** | Query classification → Specialized agent | **Complaint & Incident Routing** — Auto-route to AML team, legal, data protection, or HR based on content |
| **Evaluator-Optimizer** | AI self-correction loop | **Quality Assurance for Compliance Reports** — Generate → Evaluate → Refine until compliance standards met |

**Key Patterns for Tier 1 Agency:**
```
1. Prompt Chaining → Audit Report Generation
   Raw Data → Analysis → Review → Final Report

2. Parallelization → Risk Assessment
   Input → [Legal Agent | Financial Agent | Ops Agent | Reputation Agent] → Aggregated Risk Score

3. Routing → Incident Management
   Report → Classifier → [AML | GDPR | HR | Legal | IT Security] Agent

4. Evaluator-Optimizer → Policy Drafting
   Draft → Evaluator (compliance check) → Refine → Final Policy
```

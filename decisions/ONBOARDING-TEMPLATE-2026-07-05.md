WEEK 2 — CONFIG (the technical setup)
================================================================

```yaml
client: acme
tier: retainer
monthly_fee_cents: 250000
setup_fee_cents: 10000
billing_day: 1  # invoice on the 1st of each month

agents:
  monitor:
    sources:
      - https://www.fincen.gov/news/news-releases
      - https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:32016R0679

    compliance_matrix_path: clients/acme/compliance_matrix.yaml

      - https://acme.com

    weekly_post_day: monday

```

================================================================
WEEK 3 — SHADOW MODE (no sends, just drafts)
================================================================

  Daily standup (15 min, 9:00 UTC):
    - [ ] Review last 24h of agent drafts
    - [ ] Flag any false positives
    - [ ] Adjust thresholds if needed
    - [ ] Sign off on next batch

  Friday: send 1-page shadow report to client:
    - 21 days of agent drafts
    - What would have been caught
    - What would have been drafted
    - What would have been qualified
    - What would have been invoiced

  Outcome: client sees the work BEFORE it goes live.

================================================================
WEEK 4 — LIVE + FIRST INVOICE
================================================================

  Day 1:  flip auto_send: true on outreach + invoice
  Day 2-7: 5-min daily check-in
  Day 14:  first month-end report (auto-generated PDF)
  Day 30:  first $2,500 invoice via Stripe
  Day 31:  "first month" email to client with case-study ask

  Client success milestone (Day 30):
    - [ ] 8 agents confirmed running for 30 days
    - [ ] First invoice paid
    - [ ] First month-end report delivered
    - [ ] Client can leave anytime
    - [ ] Ask: "Can I use you as a case study for the next 7 clients?"

================================================================
RETAINER RENEWAL + CHURN PREVENTION
================================================================

  Monthly:
    - [ ] $2,500 invoice auto-charged on day 1
    - [ ] Daily Telegram digest
    - [ ] Weekly risk-snapshot
    - [ ] 1 thought-leadership blog post
    - [ ] Daily 18:00 standing review (your side)

  Quarterly:
    - [ ] 1-hour quarterly business review (QBR) call
    - [ ] Stack config refresh (add new data sources, drop dead ones)
    - [ ] Framework update (e.g. add EU AI Act when in scope)
    - [ ] Case study / testimonial ask

  Annually:
    - [ ] Renewal conversation (1 month before anniversary)
    - [ ] 12-month review: how many hours saved, fines avoided, etc.
    - [ ] Price tier review (1 client in 8 should grow to $5K/mo by year 2)

  Churn signals (any 2 = at-risk, send personal email):
    - [ ] <3 responses to daily digests in a week
    - [ ] >1 missed QBR in a quarter
    - [ ] "Can we pause for a month?" request
    - [ ] 1 regulatory fine during the retainer period
    - [ ] CFO/COO turnover (new person might not see the value)

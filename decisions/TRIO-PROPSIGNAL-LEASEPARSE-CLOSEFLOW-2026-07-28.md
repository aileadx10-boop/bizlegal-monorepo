## 3 — Cross-sell architecture (the multiplier)

Shared Supabase spine: `trio_properties` (one row per property) → `propsignal_reports`, `leaseparse_leases`, `closeflow_transactions` all FK into it.

Property lifecycle lock: **report → parse → transaction → renewal**:
- PropSignal report delivered → "Track this property's lease dates?" (LeaseParse CTA)
- LeaseParse abstract parsed → critical dates near? → "Create a closing workspace?" (CloseFlow CTA)
- CloseFlow transaction created → lease PDF detected → LeaseParse CTA
- Weekly cross-sell nudge cron (Mon 10:00 UTC) emails users of one hand who haven't tried the others.

Ops events flow through the existing HMAC chain: sources `propsignal | leaseparse | closeflow` added to `@bizlegal/ops-log` + hub `ALLOWED_SOURCES` (2026-07-28). No new event types.

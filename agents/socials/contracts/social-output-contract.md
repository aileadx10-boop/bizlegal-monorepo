# Social Output Contract

All MySocialsAssistant atomic skills should standardize around this output shape:

- Campaign
- Platform
- Variant
- Media Required
- CTA
- Approval Status
- Scheduled Time
- Publish State
- Next Step
- Risk / Blocker

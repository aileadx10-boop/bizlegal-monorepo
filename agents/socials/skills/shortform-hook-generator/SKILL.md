# Shortform Hook Generator

## Overview
Use this skill when the success of a short-form video depends on the first line or first visual beat.
The output is hook options with strategic notes, not a full script.

## Required Inputs
- Video idea
- Audience
- Platform
- Core tension
- Desired outcome

## Hook Types
- Contrarian claim
- Pain callout
- Curiosity gap
- Mistake warning
- Result promise
- Before/after contrast
- Operator lesson

## Operating Sequence
1. Identify the core tension.
2. Generate hook options by type.
3. Score each hook for clarity, tension, and relevance.
4. Recommend the strongest hook.
5. Flag claims that need proof.

## Rules
- Hooks must be specific, not motivational.
- Avoid clickbait that the video cannot satisfy.
- Prefer tension over cleverness.
- Keep short-form hooks fast and direct.
- Flag unsupported result claims.

## Common Mistakes
- Writing generic hooks
- Creating curiosity with no payoff
- Overpromising
- Choosing the clever hook instead of the clear hook

# Content Performance Review

## Overview
Use this skill after posts have been published or when performance data is available.
The output is a decision-ready improvement brief, not a vanity analytics report.

## Required Inputs
- Campaign
- Platform
- Published post or post set
- Available metrics
- Qualitative engagement notes
- Business objective

## Metrics To Inspect
Use whichever are available:
- Impressions
- Reach
- Engagements
- Clicks
- Saves
- Comments
- Shares
- Follows
- Leads or replies

## Operating Sequence
1. Identify the campaign objective.
2. Compare performance against that objective.
3. Separate signal from vanity metrics.
4. Extract what worked and what failed.
5. Recommend the next content action.

## Signal Rules
- For LinkedIn, prioritize replies, profile visits, saves, and qualified comments over raw likes.
- For Facebook, prioritize comments, shares, and clicks over passive reach.
- For Pinterest, prioritize saves, outbound clicks, and topic fit over impressions alone.
- Treat weak data as directional, not conclusive.

## Rules
- Do not optimize for vanity metrics alone.
- Tie every recommendation back to the campaign objective.
- Separate platform-specific insight from general content insight.
- If data is thin, recommend a test rather than a conclusion.

## Common Mistakes
- Calling a post successful because it got likes
- Ignoring platform-specific signals
- Drawing conclusions from one weak data point
- Reporting metrics without next actions

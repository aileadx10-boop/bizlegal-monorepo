# Carousel Brief Generator

## Overview
Use this skill when an Instagram idea needs sequential visual explanation.
The output is a slide-by-slide carousel brief for design or generation.

## Required Inputs
- Campaign or source idea
- Audience
- Core message
- Desired number of slides or default range
- CTA
- Proof or examples

## Operating Sequence
1. Decide if the idea deserves a carousel.
2. Define the carousel promise.
3. Sequence the slides.
4. Specify on-slide text and visual direction.
5. Add caption and CTA guidance.

## Default Slide Logic
Use 5-8 slides unless instructed otherwise:
1. Hook / promise
2. Problem or tension
3. Core insight
4. Framework or steps
5. Example or implication
6. Practical takeaway
7. CTA or save/share prompt

## Rules
- Use carousels for sequence, frameworks, or education.
- First slide must earn the swipe.
- Each slide should do one job.
- On-slide text must be concise.
- If proof is missing, avoid case-study-style framing.

## Common Mistakes
- Making slides too text-heavy
- Weak first slide
- No logical sequence
- CTA that does not match the carousel promise

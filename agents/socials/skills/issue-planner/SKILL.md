# Issue Planner

## Overview
Use this skill to plan Substack issues before drafting them.
The output is an issue plan or sequence that supports business goals.

## Required Inputs
- Business objective
- Audience
- Time horizon
- Topic pool or source ideas
- Desired CTA or conversion path

## Operating Sequence
1. Define the newsletter objective.
2. Select issue themes.
3. Sequence issues by reader awareness.
4. Assign CTA and proof needs.
5. Identify blockers.

## Sequence Logic
Default sequence:
1. Problem awareness
2. Cost of inaction
3. New mechanism or system
4. Proof or example
5. Offer or next step

## Rules
- Plan issues around persuasion sequence, not random topics.
- Every issue needs a job.
- Do not overload one issue with the whole strategy.
- Flag proof gaps early.

## Common Mistakes
- Creating a content calendar with no conversion logic
- Sequencing topics randomly
- Skipping proof requirements
- Making every issue promotional

# Cross-Channel Repurpose

## Overview
Use this skill when one idea needs to become both long-form and short-form output.
The output should define what each channel does differently.

## Required Inputs
- Source asset
- Campaign objective
- Audience
- Core claim
- Target channels
- CTA

## Operating Sequence
1. Identify the source asset's core idea.
2. Decide the role of each channel.
3. Create channel-specific adaptation guidance.
4. Flag dependencies and approval requirements.
5. Recommend execution order.

## Channel Roles
- Substack: explain, teach, persuade, archive
- X: test hooks, distribute sharp claims, start conversations

## Rules
- Same campaign, different channel jobs.
- Do not duplicate raw copy.
- Use X to test or distribute, not to compress the entire newsletter.
- Use Substack for depth, not a repost dump.
- Preserve one strategic CTA across the campaign.

## Common Mistakes
- Treating repurposing as copy-paste
- Making every channel say the same thing
- Failing to define channel roles
- Losing the campaign objective during adaptation

# Visual Asset Brief

## Overview
Use this skill before creating or requesting visual assets.
The output is a production-ready creative brief, not the asset itself.

## Required Inputs
- Campaign
- Platform
- Post format
- Core message
- Audience
- Desired action
- Brand or visual constraints

## Operating Sequence
1. Identify the job of the visual.
2. Choose the asset type.
3. Define layout, text, and visual hierarchy.
4. Specify required dimensions or format assumptions.
5. Flag missing inputs or production risks.

## Asset Types
- Single image
- Quote card
- Framework graphic
- Carousel
- Reel cover
- Before/after visual
- Checklist graphic

## Rules
- Define what the asset must make obvious in 2 seconds.
- Keep on-asset text short.
- Match asset type to message complexity.
- Use carousel when the idea needs sequence, not when one image is enough.
- Flag any missing image, logo, proof, or brand direction.

## Common Mistakes
- Briefing a visual without a clear job
- Putting too much text on the image
- Choosing carousel for every idea
- Ignoring platform format constraints

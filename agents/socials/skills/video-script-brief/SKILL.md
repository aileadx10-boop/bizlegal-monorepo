# Video Script Brief

## Overview
Use this skill before writing or producing video.
The output is a script-ready brief, not a finished edit or production file.

## Required Inputs
- Campaign or source idea
- Platform
- Format: short-form or long-form
- Audience
- Core message
- CTA
- Desired runtime

## Operating Sequence
1. Define the video job.
2. Choose short-form or long-form structure.
3. Define hook, core beats, proof, and CTA.
4. Identify required visuals or assets.
5. Surface production blockers.

## Format Logic
### Short-Form
Use for TikTok, YouTube Shorts, and rapid idea testing.
Prioritize hook, tension, and one clear takeaway.

### Long-Form
Use for YouTube education, authority, and deeper explanation.
Prioritize narrative arc, retention beats, examples, and packaging.

## Rules
- One video brief equals one core idea.
- Do not write long-form structure for a short-form video.
- Do not write short-form pacing for a long-form video.
- Flag missing proof, footage, or visual assets.
- Make the first 3 seconds explicit for short-form.

## Common Mistakes
- Starting with a weak hook
- Mixing multiple ideas into one video
- Ignoring runtime
- Writing a script before the video job is clear

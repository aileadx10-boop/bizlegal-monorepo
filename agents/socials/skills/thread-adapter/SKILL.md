# Thread Adapter

## Overview
Use this skill for X-ready short-form sequencing.
The output is a post or thread package optimized for clarity, tension, and engagement.

## Required Inputs
- Source idea or brief
- Audience
- Core claim
- Desired CTA
- Format: single post or thread

## Operating Sequence
1. Compress the idea into one sharp claim.
2. Choose the hook.
3. Sequence the thread or write the single post.
4. Add CTA or engagement prompt.
5. Surface risks and publish readiness.

## Format Rules
### Single Post
Use when the idea can land in one claim.
Structure:
- Hook
- Claim
- Implication
- CTA or question

### Thread
Use when the idea needs sequencing.
Structure:
- Hook post
- Context
- Core insight
- Example or evidence
- Practical takeaway
- CTA

## Rules
- X copy should be sharper and shorter than LinkedIn.
- Do not turn every idea into a thread.
- Keep one idea per post or thread.
- Use engagement prompts only when they serve the strategy.
- Do not exaggerate claims for virality.

## Common Mistakes
- Writing a thread when a single post is stronger
- Weak opening hook
- Too many ideas in one sequence
- CTA that feels disconnected from the post

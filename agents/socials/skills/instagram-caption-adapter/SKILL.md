# Instagram Caption Adapter

## Overview
Use this skill when the Instagram post concept or asset direction exists and needs platform-ready caption copy.
The output is an Instagram caption package, not a generic social post.

## Required Inputs
- Campaign or source idea
- Visual asset or asset brief
- Audience
- Core message
- CTA
- Post format: single image, carousel, reel cover, or graphic

## Operating Sequence
1. Identify what the visual does.
2. Write a caption hook that complements the visual.
3. Add the core message and implication.
4. Add CTA and hashtag guidance.
5. Flag media or approval blockers.

## Caption Structure
- Hook
- Context or tension
- Core insight
- Practical takeaway
- CTA
- Hashtag cluster

## Rules
- Caption must support the visual, not repeat it word for word.
- Keep one idea per post.
- Use hashtags as discovery support, not decoration.
- If no visual exists, route to `visual-asset-brief` first.
- Do not write Instagram like LinkedIn.

## Common Mistakes
- Writing a caption without knowing the visual
- Overloading one caption with multiple points
- Using generic hashtags
- Burying the CTA

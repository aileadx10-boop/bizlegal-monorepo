# YouTube Package Builder

## Overview
Use this skill after a YouTube video concept or script brief exists.
The output is a packaging plan that helps the video earn clicks and hold viewer expectation.

## Required Inputs
- Video concept or script brief
- Audience
- Core promise
- Format: long-form or Shorts
- CTA
- Proof or examples

## Operating Sequence
1. Define the video promise.
2. Generate title options.
3. Define thumbnail direction.
4. Draft description and CTA.
5. Add chapters or structure notes when relevant.

## Package Elements
- Title options
- Thumbnail concept
- Description
- CTA
- Chapters
- Tags or topic notes
- Risk / blocker

## Rules
- Title and thumbnail must sell the same promise.
- Do not use vague authority titles.
- Description should support conversion and search without becoming bloated.
- Chapters belong to long-form unless a specific short-form use exists.
- Flag missing thumbnail assets.

## Common Mistakes
- Title promises one thing while thumbnail promises another
- Weak thumbnail direction
- Search-stuffed descriptions
- No CTA

# Phase 1

## Scope
- Buffer
- LinkedIn
- Facebook
- Pinterest

## Goal
Build a shared publishing core using Buffer as the execution hub and publish one content unit as a coordinated multi-platform batch.

## Atomic Skills
- social-content-brief
- social-content-adapter
- buffer-publisher
- social-approval-routing
- social-queue-review
- content-performance-review

## Rules
- Same campaign, different platform variants
- Do not publish identical raw copy to all platforms
- Buffer is the execution hub for this phase

## Success Criteria
- One source message becomes three platform-specific variants
- Buffer queue payload is correct per platform
- Approval routing blocks unsafe publishing

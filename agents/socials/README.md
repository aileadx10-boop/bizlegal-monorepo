# MySocialsAssistant

Separate system for public publishing, content adaptation, scheduling, approval, and performance review.

This system is intentionally isolated from the Executive Assistant workspace logic.

## Mission
Build a phased social publishing assistant that starts with Buffer-managed multi-platform batching and expands into newsletter, visual, and video channels over time.

## Phase Rollout
1. Phase 1: Buffer + LinkedIn + Facebook + Pinterest
2. Phase 2: Substack + X
3. Phase 3: Instagram
4. Phase 4: TikTok + YouTube

## Boundary
- Keep founder ops, CRM, projects, invoices, and internal execution in the main Executive Assistant system.
- Keep publishing, repurposing, queue management, approvals, and content analytics here.
